# Анализ повторных покупок в e-commerce

Аналитический проект на реальных данных британского интернет-магазина. Цель: определить факторы, которые отличают возвращающихся клиентов от тех, кто совершает только одну покупку, и сформулировать продуктовые рекомендации, опирающиеся на статистический анализ. Стек: Python, pandas, scipy, statsmodels.

## Контекст и значимость задачи

Экономика любого ритейлера или маркетплейса определяется балансом между стоимостью привлечения клиента (CAC) и его пожизненной ценностью (LTV). Привлечение оплачивается единовременно, тогда как окупаемость зависит от того, совершит ли клиент повторные покупки. Соответственно, способность заранее идентифицировать клиентов с высокой вероятностью возврата напрямую влияет на эффективность маркетингового бюджета и продуктовых решений.

В рамках проекта решаются три практические задачи:
1. Количественная оценка retention в когортном разрезе.
2. Проверка статистической гипотезы о связи между поведением при первой покупке и вероятностью возврата.
3. Подготовка дизайна A/B-теста для проверки рекомендаций в продуктовой среде.

## Источник данных

Используется датасет [Online Retail II](https://archive.ics.uci.edu/ml/datasets/Online+Retail+II) из репозитория UCI Machine Learning Repository. Он содержит реальные транзакции британского онлайн-ритейлера за 2009-2011 годы (около миллиона строк) и включает все поля, необходимые для retention-аналитики: уникальный идентификатор клиента, дату каждой транзакции, цену и количество, страну доставки.

Загрузка данных автоматизирована:

```bash
python src/download_data.py
```

## Применённые методы

Набор методов выбран сознательно компактным: каждый из них допускает прозрачную интерпретацию и может быть защищён в формате «вопрос-ответ».

- Когортный анализ retention с визуализацией в виде тепловой карты.
- t-критерий Уэлча для двух независимых выборок.
- Расчёт минимально необходимого размера выборки для A/B-теста (`statsmodels`, формула двух пропорций).
- Монте-Карло симуляция дизайна A/B-теста для эмпирической проверки мощности и доли ложноположительных результатов.
- RFM-сегментация на основе квинтилей.

ML-модели сознательно не использовались. Поставленная бизнес-задача решается методами описательной и инференциальной статистики, а интерпретируемость результатов имеет приоритет над предсказательной точностью.

## Ключевые результаты

1. Основное падение retention происходит в первый месяц после первой покупки: со 100% до приблизительно 22%. Дальнейшее снижение носит постепенный характер. Это определяет окно эффективного воздействия как первые тридцать дней.
2. Размер первого чека статистически значимо связан с вероятностью возврата (t-критерий Уэлча, p < 0.001). Клиенты с первым чеком выше медианы возвращаются заметно чаще.
3. Декабрьские когорты демонстрируют пониженный retention по сравнению со всеми остальными. Вероятная причина: преобладание среди них покупателей подарков, не являющихся целевой аудиторией бренда.
4. Сегмент с высоким первым чеком приносит за период наблюдения кратно большую выручку. Эффект объясняется не только разовым AOV, но и большей частотой повторных покупок и большей продолжительностью «жизни» клиента.
5. Концентрация выручки соответствует правилу Парето: примерно 20% клиентов формируют около 80% совокупной выручки.

## Главная рекомендация

Триггерные кампании реактивации, рассылаемые в первые 14 дней после первой покупки, следует таргетировать исключительно на сегмент клиентов с первым чеком ниже медианы. В этом сегменте сосредоточен наибольший потенциал прироста retention, тогда как сегмент с высоким чеком и без вмешательства демонстрирует достаточный уровень возврата. Полный дизайн A/B-теста, включая расчёт необходимого размера выборки и проверку мощности через симуляцию, представлен в ноутбуке 05.
