# Что возвращает клиента: анализ повторных покупок в e-commerce

> Pet-проект для стажировки аналитиком в Яндексе. Простые методы, понятные выводы, продуктовое мышление.

## Бизнес-вопрос

**Что отличает клиентов, которые возвращаются за второй покупкой, от тех, кто уходит после первой?**

Любой маркетплейс — Маркет, Еда, Лавка — окупает CAC только за счёт повторных покупок. Если ты понимаешь, какие клиенты вернутся, ты можешь:
- не тратить деньги на удержание тех, кто и так вернётся;
- сфокусировать рекламные бюджеты и персональные кампании на тех, у кого высокий риск ухода;
- править онбординг и продуктовый опыт под сегмент, который чаще уходит.

## Данные

[Online Retail II](https://archive.ics.uci.edu/ml/datasets/Online+Retail+II) — реальные транзакции британского интернет-магазина за 2009–2011, ~1 млн строк, открытый датасет UCI Machine Learning Repository. Поля: `Invoice`, `StockCode`, `Quantity`, `InvoiceDate`, `Price`, `Customer ID`, `Country`.

Скачать данные:
```bash
python src/download_data.py
```

## Методы

Сознательно используются только два метода — лучше глубоко защитить два, чем поверхностно перечислить десять.

1. **Когортный анализ retention.** Группируем клиентов по месяцу первой покупки, считаем, какой процент возвращается через 1, 2, ..., N месяцев. Получаем тепловую карту, на которой сразу видно, какие когорты «лучше».
2. **t-критерий Стьюдента для двух независимых выборок.** Сравниваем средний чек первой покупки у клиентов, которые вернулись (`returned`), и у тех, кто не вернулся (`one-time`). Проверяем, реальна ли разница или это случайность.

## Ключевые находки

- **Retention падает быстро:** через 1 месяц возвращается ~22% клиентов, через 6 месяцев — ~12%. Стандартная картина для розничного e-commerce.
- **Размер первого чека предсказывает возврат.** Средний чек первой покупки у вернувшихся клиентов — около £580; у однократных — около £290. Разница статистически значима (t-тест, p < 0.001).
- **Декабрьские когорты возвращаются хуже** — типичные «подарочные» покупатели, которые не были в целевой аудитории.

## Главная рекомендация (одной строкой)

> **Запускать триггерные кампании реактивации в первые 14 дней после первой покупки таргетированно — только для клиентов с чеком ниже медианы. У них и потенциал роста выше, и стоимость кампании на повышенный чек окупается лучше.**
