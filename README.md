# Что возвращает клиента: анализ повторных покупок в e-commerce

Pet-проект, в котором я разбираю поведение клиентов британского интернет-магазина и пытаюсь понять, что отличает тех, кто возвращается, от тех, кто покупает один раз и уходит. Стек простой: Python, pandas, scipy, statsmodels.

## О чём вообще проект

Любой маркетплейс или ритейлер живёт за счёт повторных покупок. Привлечь клиента стоит денег, и эти деньги отбиваются только если он вернётся. Поэтому продуктовые команды постоянно думают над одним и тем же вопросом: какие клиенты вернутся, а какие нет, и можно ли это понять заранее.

В проекте я отвечаю на этот вопрос на реальных данных, считаю экономику возврата и проектирую A/B-тест, который проверил бы практический смысл найденной закономерности.

## Данные

[Online Retail II](https://archive.ics.uci.edu/ml/datasets/Online+Retail+II) с UCI Machine Learning Repository. Это реальные транзакции британского интернет-магазина за 2009-2011, около миллиона строк. Скачать можно прямо скриптом:

```bash
python src/download_data.py
```

В датасете лежит то, что нужно для retention-аналитики: уникальный идентификатор клиента, дата каждой покупки, цена и количество, страна доставки.

## Какие методы использую

Сознательно ограничиваюсь набором, который можно объяснить вслух без шпаргалки:

- Когортный анализ retention (тепловая карта по месяцам).
- t-критерий Уэлча для двух независимых выборок.
- Расчёт размера выборки через formula для двух пропорций (statsmodels).
- Монте-Карло симуляция, чтобы валидировать дизайн A/B-теста.
- RFM-сегментация на квинтилях.

ML-моделей здесь нет специально. На бизнес-вопрос проекта они не нужны: простая сегментация и аккуратная статистика отвечают на него лучше, чем какой-нибудь градиентный бустинг с интерпретацией через SHAP.

## Что нашлось в данных

1. Главное падение retention происходит в первый месяц: со 100% до примерно 22%. Дальше кривая деградирует медленно. Значит, ключевое окно для борьбы за повторную покупку это именно первые тридцать дней.
2. Размер первого чека статистически значимо связан с возвратом (t-тест Уэлча, p сильно меньше 0.001). Клиенты, чей первый чек выше медианы, возвращаются заметно чаще.
3. Декабрьские когорты возвращаются хуже остальных. Типичная история с подарочными покупателями, которые приходят один раз и уходят.
4. Сегмент с высоким первым чеком приносит за весь период наблюдения кратно больше денег, не только из-за чека, но и за счёт большего числа повторных покупок.
5. Топ 20% клиентов дают около 80% выручки. Стандартное Парето-распределение, типичное для розницы.

## Главная рекомендация

Триггерные кампании реактивации в первые две недели после первой покупки нужно запускать таргетированно, только на клиентов с чеком ниже медианы. У них и потенциал прироста выше, и стоимость ошибки в общей кампании выше, чем кажется. Идеи для проверки сформулированы как готовый дизайн A/B-теста (ноутбук 05).
